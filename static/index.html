Open Cloud Setup
CONFIGURE YOUR ROBLOX OPEN CLOUD API KEY
✓
Mode
2
Setup
3
Verify
ℹ Open Cloud API does not support sending DMs to users. The auto-notify feature will be disabled when using this mode.
1
Go to create.roblox.com and sign in with your moderator account.
2
In the left sidebar click Credentials, then click Create API Key.
3
Give it a name like SENTINEL-MOD. Under Access Permissions add assets:read, assets:write. Under Security you can restrict by IP if desired.
4
Click Save & Generate Key. Copy the key — it won't be shown again.
5
Enter your Creator ID: go to your Roblox profile, the number in the URL is your User ID.
6
If SENTINEL cannot auto-fetch your groups, you can paste a group URL manually on the Groups tab.
✓ API Key saved (encrypted) ••••••••••••••••••••
